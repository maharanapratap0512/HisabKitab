01

What is ng-sutramui?

ng-sutramui is an Angular component library that reads schema from your sutramEngine backend and auto-generates menus, forms, tables, and bulk-entry UIs — without writing a single column definition in the frontend.

It ships three independent layers. Use only what you need — PrimeNG, Bootstrap, or just the headless core services to build your own UI.

LayerImport fromRequires
Coreng-sutramui/coreAngular only — zero UI deps
PrimeNGng-sutramui/primengprimeng, @primeng/themes, primeicons
Bootstrapng-sutramui/bootstrapbootstrap, @ng-select/ng-select

Installation

Install only what you need. Peer dependencies are optional — npm will suggest them automatically.

PrimeNGbash
npm install ng-sutramui primeng
Bootstrapbash
npm install ng-sutramui bootstrap
Core only — custom UIbash
npm install ng-sutramui
ℹExport to Excel/PDF uses xlsx and jspdf — both loaded lazily via dynamic import. No bundle cost until user clicks Export.
03

Setup

Call provideSutramUI() once in app.config.ts. Every component and service reads from this config automatically.

PrimeNG — app.config.tsts
import { provideSutramUI } from 'ng-sutramui/core';
import { providePrimeNG }  from 'primeng/config';
import Aura from '@primeng/themes/aura';

export const appConfig = {
  providers: [
    provideSutramUI({
      apiBase: 'http://localhost:3000/api',
      theme:   'primeng',
      compact: false,
    }),
    providePrimeNG({
      theme: { preset: Aura, options: { darkModeSelector: '.dark' } }
    }),
  ]
};
Bootstrap — app.config.tsts
import { provideSutramUI } from 'ng-sutramui/core';

export const appConfig = {
  providers: [
    provideSutramUI({
      apiBase: 'http://localhost:3000/api',
      theme:   'bootstrap',
      compact: true,  // global compact
    }),
  ]
};
Config keyTypeDefaultDescription
apiBasestring—sutramEngine API URL e.g. http://localhost:3000/api
headersRecord<string,string>{}Optional HTTP headers added to every request
theme'primeng' | 'bootstrap''primeng'Which component layer is active
compactbooleanfalseGlobal compact mode — per-component [compact] overrides this

06

Core Services

Import from ng-sutramui/core. Zero UI dependency — use in any Angular project regardless of UI library.

ServiceWhat it does
SutramSchemaServiceFetches + caches schemas, dropdown data, CRUD operations. shareReplay(1) — one HTTP call per session per key.
SutramFormServiceBuilds Angular FormGroup from schema. Validates, patches (edit mode), submits POST/PUT.
SutramTableServiceManages table state via signals — rows, total, page, loading. Pagination, filter, sort, inline update.
SutramDropdownServiceIn-memory dropdown cache. Local search (no API). Dependent filter by parent _id. Dirty flag for refresh.
SutramBunchServiceMaster-detail / bulk form logic. Auto-push new row when required fields filled. Calc fields (qty*rate). Submit validation.
07

Compact Mode

Compact mode reduces font sizes, padding, input heights, table cell spacing — everything via CSS variables. Works on both PrimeNG and Bootstrap.

Global compact (app.config.ts)ts
provideSutramUI({ compact: true })
Per-component overridehtml
<!-- global ON, this table normal -->
<sutram-table table="city" [compact]="false" />

<!-- global OFF, just this form compact -->
<sutram-form  table="city" [compact]="true"  />
ℹCompact overrides all --sui-* CSS variables. PrimeNG component sizes are also reduced via scoped overrides in sutramui-compact.css.
08

Dark Mode

PrimeNG

Set darkModeSelector: '.dark' in providePrimeNG(). sutram-menu's theme toggle adds/removes .dark on document.body. Preference saved to localStorage.

app.config.tsts
providePrimeNG({
  theme: {
    preset: Aura,
    options: { darkModeSelector: '.dark' }
  }
})

Bootstrap

Bootstrap 5.3+ native dark mode. sutram-menu toggle sets data-bs-theme="dark" on <html>. All ng-select styles respond automatically via Bootstrap CSS variables.

Automatichtml
<!-- sutram-menu handles this automatically -->
<sutram-menu [showThemeToggle]="true" />

sutram-form

Auto-generates a reactive form from GET /_sutram/schema/:table. Developer controls placement — no opinionated dialog wrapper. Wrap in p-dialog or Bootstrap modal yourself.

Usagehtml
<!-- Auto-fetch schema -->
<sutram-form table="city" (onSubmit)="save($event)" />

<!-- Edit mode -->
<sutram-form table="city" [record]="selectedRow"
  submitLabel="Update"
  (onSubmit)="update($event)"
  (onCancel)="close()" />

<!-- Readonly view -->
<sutram-form table="city" [record]="row" [readonly]="true" />

<!-- In PrimeNG dialog -->
<p-dialog [(visible)]="showForm">
  <sutram-form table="city"
    (onSubmit)="saved($event)"
    (onCancel)="showForm=false" />
</p-dialog>

sutram-table

Schema-driven data table with pagination, global filter, inline editing, and Excel/PDF export. Table headers are always colorful — configurable via inputs.

Usagehtml
<!-- Simple -->
<sutram-table table="city" />

<!-- Inline edit — small tables (city, state, category) -->
<sutram-table
  table="city"
  [inlineEdit]="true"
  [actions]="['delete']"
  (onSave)="saved($event)"
/>

<!-- Full actions — large tables -->
<sutram-table
  table="product"
  [actions]="['view','edit','delete']"
  [rows]="25"
  (onEdit)="openForm($event)"
  (onDelete)="deleted($event)"
/>

<!-- Custom export headers and colors -->
<sutram-table
  table="product"
  exportHeaderColor="#10B981"
  exportHeaderTextColor="#fff"
  [exportColumns]="myColumns"
/>

sutram-bunch-form

Master-detail and bulk entry form. Schema fetched from GET /_sutram/bunch-schema/:formName. Two modes determined by schema — no code change needed.

Master + Detail (Voucher)

Usagehtml
<sutram-bunch-form
  schema="voucher_entry"
  (onSubmit)="saved($event)"
/>

Detail Only (Bulk City)

Usagehtml
<sutram-bunch-form
  schema="city_bulk"
  (onSubmit)="saved($event)"
/>
✓Auto-push: when all required fields of a row are filled → new empty row appears automatically. Minimum 1 row always kept.
ℹSubmit payload: {"master": {}, "details": [{...}]}. master is {} in detail-only mode. Sent to POST /_sutram/bunch/:formName.
InputTypeDescription
schemastring (required)Bunch form name — fetches from /_sutram/bunch-schema/:name
submitLabelstringSubmit button label. Default: 'Submit'
showCancelbooleanShow cancel button. Default: true
compactbooleanOverride global compact

sutram-bunch-table

Displays master-detail data grouped. Each master row = expandable card showing its detail rows. Export includes all groups in one sheet/PDF.

Usagehtml
<sutram-bunch-table
  schema="voucher_entry"
  [masterData]="vouchers"
  [detailData]="voucherItems"
  detailForeignKey="voucher_id"
  [actions]="['edit','delete']"
  (onEdit)="editVoucher($event)"
  (onDelete)="deleted($event)"
/>
ℹdetailForeignKey is auto-detected from schema if not provided — uses the first dropdown ref field in detailFields.

Build Your Own UI

Import from ng-sutramui/core — inject the services you need, build your own templates with any UI library.

Custom table component examplets
import { SutramTableService, SutramSchemaService } from 'ng-sutramui/core';

@Component({ ... })
export class MyTableComponent implements OnInit {
  private tableService = inject(SutramTableService);
  private schemaService = inject(SutramSchemaService);

  schema = signal<SutramTableSchema | null>(null);

  // Proxy signals from service — reactive
  rows    = this.tableService.rows;
  total   = this.tableService.total;
  loading = this.tableService.loading;
  page    = this.tableService.page;

  ngOnInit() {
    this.schemaService.getTableSchema('city').subscribe(s => {
      this.schema.set(s);
      this.tableService.init('city', { limit: 20 });
      this.tableService.load().subscribe();
    });
  }

  nextPage() { this.tableService.nextPage()?.subscribe(); }
}

EndpointUsed byReturns
GET /_sutram/menusutram-menu{ tables[], reports[] }
GET /_sutram/schema/:tablesutram-form, sutram-tableSutramTableSchema
GET /_sutram/bunch-schema/:namesutram-bunch-form/tableSutramBunchSchema

GET /:refTable?_limit=9999dropdown cache{ result[] }
POST /:tablesutram-form (new){ result: savedRow }
PUT /:table/:idsutram-form (edit){ result: updatedRow }
DELETE /:table/:idsutram-table delete{ result: { deleted: N } }
POST /_sutram/bunch/:namesutram-bunch-form{ result: any }
◈All responses wrapped in { success: true, result: T, total?, count? } or { success: false, error: string } — standard sutramEngine router envelope.
