01

What is sutramcore-mysql?

sutramcore-mysql is the async MySQL adapter for sutramcore. It provides MySQLSutram and MySQLBaseTable — the async equivalent of sutramCore's Sutram and BaseTable.

Your existing schema.js works unchanged — same defineTable, same col builders, same join declarations. The only difference is that all CRUD methods return Promises.

◈await on a sync function is always safe in JavaScript — no error, no warning. So you can write all your code with await and switch between SQLite and MySQL by just changing the connection setup.

Installation

terminalbash
npm install sutramcore-mysql mysql2

# sutramcore stays unchanged — install separately if using SQLite too
npm install sutramcore better-sqlite3

mysql2 is a peer dependency — install it explicitly. sutramcore-mysql does not install it for you to avoid version conflicts.

03

Connect

Create a MySQLSutram instance and call .connect(). It creates a connection pool and tests the connection immediately.

database/db.jsjs
const { MySQLSutram } = require('sutramcore-mysql');
const schema           = require('./schema');  // exact same schema.js

const db = await new MySQLSutram({
  host:             'localhost',
  port:             3306,        // default
  user:             'root',
  password:         'secret',
  database:         'myapp',
  connectionLimit:  10,          // pool size, default 10
  schema,
}).connect();

module.exports = { db };

Or pass existing adapter

with pre-configured MySQLAdapterjs
const { MySQLSutram, MySQLAdapter } = require('sutramcore-mysql');

const adapter = new MySQLAdapter({
  host: 'localhost', user: 'root',
  password: 'secret', database: 'myapp',
});
await adapter.connect();

const db = new MySQLSutram({ adapter, schema });
// no .connect() needed — adapter already connected

Insert

insert examplesjs
const product = db.table('product');

// full: true (default) — returns complete joined object
const row = await product.insert({
  name:        'Wireless Mouse',
  price:       799,
  category_id: 2,
});
// row.category = { name: 'Electronics' }  ← joined

// full: false — returns just insertId (faster, use in transactions)
const id = await product.insert({ name: 'USB Hub' }, false);

Get / GetAll

get examplesjs
const product = db.table('product');

// getById — always full with joins
const row = await product.getById(1);

// getOne — with where
const row = await product.getOne({ name: 'USB Hub' });
const row = await product.getOne("price < 500 AND active = 1");

// getAll
const rows = await product.getAll({ active: 1 });
const rows = await product.getAll({ active: 1 }, {
  orderBy: 'price ASC',
  limit:   20,
  offset:  0,
  full:    true,   // false = no joins, faster
});

09

Joins

All three join types work exactly like sutramCore. Schema declaration is identical — MySQL uses JSON_OBJECT and JSON_ARRAYAGG internally instead of SQLite's functions.

schema.js — same as sutramCore, no changesjs
const { defineTable, col } = require('sutramcore');  // col from sutramcore

module.exports = {
  ...defineTable('category', {
    _id:  col.id(),
    name: col.string().required(),
  }),

  ...defineTable('product', {
    _id:         col.id(),
    name:        col.string().required(),
    category_id: col.ref('category._id', {  // hasOne
                     as: 'category', select: ['name'],
                 }),
  }, {
    reviews: {                                  // hasMany
      hasMany: true, table: 'review',
      on: 'product_id', target: '_id',
      as: 'reviews', select: ['_id', 'rating'],
    },
  }),
};
result — joins work same as SQLitejs
const row = await db.table('product').getById(1);
// row.category = { name: 'Electronics' }   ← hasOne
// row.reviews  = [ { _id: 1, rating: 5 } ] ← hasMany
// row.tags     = [ { _id: 2, label: 'new' } ] ← manyToMany

WHERE Clause

Same two formats as sutramCore — object or raw string.

object safe
// AND conditions, bound params
{ active: 1 }
{ active: 1, category_id: 2 }
// safe — no SQL injection
string raw SQL
// complex conditions
"price BETWEEN 100 AND 500"
"name LIKE '%keyboard%'"
"cat = 1 OR cat = 2"

Transactions

Transactions use a scoped connection — all operations in transaction(fn) run on the same MySQL connection. Commits on success, rolls back on any throw.

automatic — recommendedjs
const orderId = await db.transaction(async (tx) => {
  // tx is scoped to this transaction's connection
  const id = await tx.table('order').insert(
    { customer_id: 5, status: 'pending' },
    false
  );

  for (const item of cart) {
    await tx.table('order_item').insert({
      order_id:   id,
      product_id: item.product_id,
      qty:        item.qty,
    }, false);
  }

  return id;
});
⚠Inside transaction(fn), always use tx.table() — not the outer db.table(). The tx object is bound to the transaction connection. Using db.table() inside will bypass the transaction.

Manual control

manual begin / commit / rollbackjs
await db.begin();
try {
  await db.table('order').insert(data, false);
  await db.commit();
} catch (e) {
  await db.rollback();
  throw e;
}

Raw Query

db.query / db.queryOnejs

procedure() — same pattern as table()

Access CTE reports and stored procedures the same way you access tables. Returns a cached ProcedureHandle.

database/reports.jsjs
module.exports = [
  {
    report_name: 'monthly_sales',
    report_type: 'cte',
    cte_sql:     `SELECT strftime('%Y-%m', date) as month, SUM(amount) as revenue
                 FROM orders WHERE date >= :from GROUP BY month`,
    params: [{ name: 'from', type: 'string', default: '2024-01-01' }],
  },
  {
    report_name:    'generate_report',
    report_type:    'procedure',
    procedure_name: 'generate_report',
    params: [{ name: 'year', type: 'number', default: 2024 }],
  },
];
usagejs
const db = await new MySQLSutram({
  ...config, schema,
  reports: require('./reports'),
}).connect();

// CTE report
const rows = await db.procedure('monthly_sales').run({ from: '2024-06-01' });

// Stored procedure → CALL generate_report(2024)
const rows = await db.procedure('generate_report').run({ year: 2024 });

// inspect
db.procedure('monthly_sales').getParams();
db.procedure('generate_report').getMeta();

// cached — same instance
db.procedure('monthly_sales') === db.procedure('monthly_sales')  // true
MethodReturns
await .run(params?)Array of rows
.getParams()Params definition array
.getMeta(){ name, label, report_type, procedure_name, params }

With sutramEngine

Pass MySQLSutram as sutram to sutramEngine — Pattern 1. Engine detects dialect: 'mysql' automatically.

database/db.jsjs
const { MySQLSutram } = require('sutramcore-mysql');
const { SutramEngine } = require('sutramengine');
const schema = require('./schema');

const mysqlDb = await new MySQLSutram({
  host: 'localhost', user: 'root',
  password: 'secret', database: 'myapp',
  schema,
}).connect();

const engine = new SutramEngine({
  sutram: mysqlDb,   // dialect auto-detected
}).init();

module.exports = { engine };
usage — same engine API, with awaitjs
const row  = await engine.insert('product', data);
const rows = await engine.getAll('product', { active: 1 });
await engine.deleteById('product', 5);

// router — Express handles async internally
app.use('/api', engine.router());

SQLite → MySQL Migration

Same schema.js — no changes needed. Only change the connection setup in db.js.

SQLite — beforejs
const { Sutram } = require('sutramcore');
const db = new Sutram({
  dbPath: './app.db',
  schema,
});

// sync
const row = product.getById(1);
MySQL — afterjs
const { MySQLSutram } = require('sutramcore-mysql');
const db = await new MySQLSutram({
  host, user, password, database,
  schema,
}).connect();

// async — add await
const row = await product.getById(1);
✓schema.js, triggers.js, reports.js — all reusable. Only db.js changes. Add await to all CRUD calls in your services.

CLI — Import SQL File

Convert your existing MySQL database export into schema.js and reports.js automatically. Foreign keys become col.ref(), stored procedures become report definitions.

Step 1 — Export SQL from MySQL

mysqldumpbash
# command line
mysqldump -u root -p myapp > database.sql

# phpMyAdmin → Database → Export → Format: SQL → Go

Step 2 — Run CLI

terminalbash
# schema.js only
npx sutramcore-mysql import ./database.sql

# schema.js + reports.js (stored procedures bhi)
npx sutramcore-mysql import ./database.sql --reports

# custom output folder
npx sutramcore-mysql import ./database.sql --out ./src/database --reports

Step 3 — Output

17

Generated schema.js

FK columns become col.ref() with label column auto-detected. Boolean columns (tinyint(1)) mapped correctly. NOT NULL → .required().

MySQL SQLsql
CREATE TABLE `state` (
  `_id` int NOT NULL AUTO_INCREMENT,
  `state_name` varchar(100) NOT NULL,
  `country_id` int DEFAULT NULL,
  `active` tinyint(1) DEFAULT 1,
  PRIMARY KEY (`_id`),
  FOREIGN KEY (`country_id`)
    REFERENCES `country`(`_id`)
) ENGINE=InnoDB;
Generated schema.jsjs
...defineTable('state', {
  _id:        col.id(),
  state_name: col.string().required(),
  country_id: col.ref('country._id', {
    as:     'country',
    select: ['country_name'],
  }),
  active: col.boolean().default(1),
}),
⚠hasMany and manyToMany joins cannot be detected from SQL — add them manually in defineTable's third argument.

Generated reports.js

Pass --reports flag to also generate reports.js from stored procedures. IN params are detected automatically. OUT params are skipped.

MySQL stored proceduresql
CREATE PROCEDURE `monthly_sales`(
  IN from_date DATE,
  IN to_date DATE
)
BEGIN
  SELECT strftime('%Y-%m', date) as month,
         SUM(amount) as revenue
  FROM orders
  WHERE date BETWEEN from_date AND to_date
  GROUP BY month;
END;
Generated reports.jsjs
module.exports = [{
  report_name:    'monthly_sales',
  label:          'Monthly Sales',
  report_type:    'procedure',
  procedure_name: 'monthly_sales',
  params: [
    { name: 'from_date',
      type: 'string', default: null },
    { name: 'to_date',
      type: 'string', default: null },
  ],
}];
ℹAfter generation — update default: null to real default values, and update label to a human-readable name.

Use immediately after generation

database/db.jsjs
const { MySQLSutram } = require('sutramcore-mysql');
const schema  = require('./database/schema');   // generated
const reports = require('./database/reports');  // generated

const db = await new MySQLSutram({
  host: 'localhost', user: 'root',
  password: 'secret', database: 'myapp',
  schema, reports,
}).connect();

await db.procedure('monthly_sales').run({
  from_date: '2024-01-01',
  to_date:   '2024-12-31',
});
